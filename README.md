# 🎯 选择困难终结者

帮选择恐惧症患者快速做决定！零依赖，纯静态页面。

## 🚀 启动方式

**方式一：直接打开（推荐）**
双击 `index.html` 即可在浏览器中运行。

**方式二：本地服务器**
```bash
# Python
python -m http.server 8000

# Node.js (需要先装 serve)
npx serve .
```
然后打开 http://localhost:8000

## 📁 项目结构

```
renmaiwang/
├── index.html          # 主页面
├── css/
│   └── style.css       # 样式 + 动画
├── js/
│   ├── main.js         # 模式切换 + 历史记录
│   ├── basic.js        # 基础款：抛硬币、是/否、二选一
│   ├── advanced.js     # 进阶款：转盘、抽签、抓阄
│   └── fun.js          # 趣味款：数花瓣
└── README.md
```

## 🎮 功能

| 模式 | 功能 | 说明 |
|------|------|------|
| 🪙 基础款 | 抛硬币 | 3D翻转动画，正面/反面 |
| ✅ 是/否 | 随机回答 | 输入问题，给出是/否答案 |
| ⚖️ 二选一 | 两选项随机 | 输入A和B，帮你挑一个 |
| 🎡 进阶款 | 幸运转盘 | Canvas绘制的彩色转盘 |
| 🎋 抽签筒 | 签筒摇签 | 摇晃+抽取动画 |
| 📦 抓阄 | 纸团抓取 | 纸团翻动+选中特效 |
| 🌸 趣味款 | 数花瓣 | "ta爱我…不爱我…" |

## 🛠 技术栈

- HTML5 + CSS3 + 原生 JavaScript
- Canvas API（转盘绘制）
- CSS 3D Transform（硬币翻转）
- localStorage（历史记录）
- 零依赖，无框架，无构建工具
